# Stamp Page Designer

Make true-size stamp album pages, quickly, in your browser — no software to install.

Build a page by dragging stamp boxes to their real size in millimetres, on a 5 mm grid, with the spacing and mount clearance you choose. Then preview it and print it, or save it as a PDF, at 100% — so what you see on screen is what prints, stamp for stamp.

Live site: https://curious-coder08.github.io/stamp-page-designer/

- Open the tool: `stamp-page-designer.htm` (version 4.0.2)
- How to video: `how-to-video.html`
- How to documentation: `how-to.html`

A hobby project, made for collectors, by a collector. Free to use.

Albums and settings live in the browser, on the device — there is no account, no cloud copy, and no project file. Save project keeps the editable page in the browser; Print / Save as PDF is the finished output only.
